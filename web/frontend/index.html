READ THE RESULTS IN CONTEXT

Generalization is the experiment.

Both architectures use the same source recordings, 18-channel representation, and frozen patient split. Normalization is fitted on training data; checkpoints and thresholds are chosen using validation patients only.

What does the score mean?

An uncalibrated model score, not a true probability. Classification uses a fixed threshold chosen to maximize validation patient-macro F1.

Why show false positives and missed seizures?

Failures reveal limits hidden by aggregate metrics. Curated clips illustrate model behavior; their frequency does not represent the test set.

What does “full cohort” mean?

All 24 cases represent 23 individuals. Fifteen individuals train the models, four select checkpoints and thresholds, and four are held out for testing. Unsupported recordings are explicitly reported. This is a single split, not leave-one-patient-out evaluation.

What are the important limitations?

Retrospective window classification on one dataset is not clinical validation. Window recall is not event sensitivity. The four test individuals do not establish broad population performance. Any-overlap labels include seizure boundaries, and missing montage compatibility can exclude recordings.
